# Andre Ortiz — Personal Site

## What We're Building
A personal portfolio and blog for Andre Ortiz — product designer with 20 years of experience designing software, building systems, and shipping work that moves the needle.

## Positioning
**Tagline:** Design. Ship. Profit.
**Why:** Good design doesn't make things pretty. It makes things work — for customers, for teams, and for the bottom line.
**Audience:** Founders and startup operators (primary), design leadership hiring managers (secondary)

## Stack
- **Astro 5** — static site framework
- **React 19** — interactive components
- **Tailwind CSS 4** — styling
- **GSAP 3** — animations
- **Shadcn/ui + Base UI** — component primitives
- **MDX** — content authoring for blog and case studies
- **TypeScript** — type safety
- **Phosphor Icons / Lucide** — iconography

## Key Sections
- **Home** — hero, case studies grid, blog list
- **About** — bio, story, human details
- **Work** — 4 case studies with interactive demos (MDX-driven)
- **Blog** — 6 planned posts (MDX-driven, RSS feed)
