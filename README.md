## Demo Components

The interactive demos in `src/components/demos/` are currently placeholder stubs. They are functional but intended to be replaced with polished, production-quality interactive artifacts that reinforce each case study narrative. Each work page has three sections — the existing demos cover one section per page; the remaining placeholder components (`*Placeholder.jsx`) are marked for future enhancement.
